## 1. ЦЕЛЬ И ЗАДАЧИ РАБОТЫ

**Цель работы:**
Изучить ключевые концепции и принципы объектно-ориентированного программирования (ООП) в Python и преобразовать программную структуру индивидуального проекта «Сервис выбора тем курсовых работ», построенную на функциях и коллекциях словарей в ПР2, в полноценную объектную модель предметной области.

**Задачи работы:**
1. Изучить классы, объекты, конструктор `__init__`, магический метод `__str__` и передачу `self`;
2. Рассмотреть фундаментальные принципы ООП: инкапсуляцию, наследование, полиморфизм, ассоциацию и композицию;
3. Освоить применение декораторов методов класса (`@classmethod`, `@staticmethod`, `@property`);
4. Спроектировать объектную модель предметной области: выделить классы `Topic`, `Student`, `Application` и организовать их в пакете `models/`;
5. Реализовать прямое взаимодействие объектов (объект `Application` содержит прямые ссылки на экземпляры `Topic` и `Student`);
6. Адаптировать модуль `storage.py` для сериализации объектов в JSON и десериализации JSON в объекты с восстановлением связей по внешним ключам;
7. Адаптировать главный модуль `main.py` для работы со списками объектов `List[Topic]`, `List[Student]`, `List[Application]`;
8. Адаптировать и расширить модульные тесты в каталоге `tests/` для проверки состояния объектов и их методов;
9. Актуализировать проектную спецификацию в файле `README.md` и зафиксировать историю изменений в Git с префиксом `PR3:`.

## 3. ОБЪЕКТНАЯ МОДЕЛЬ ИНДИВИДУАЛЬНОГО ПРОЕКТА

### 3.1. Описание основных классов

#### 1. Класс `Topic` (`models/topics.py`)
Описывает тему курсовой работы:
- **Атрибуты:** `id` (int), `title` (str), `discipline` (str), `supervisor` (str), `min_course` (int), `min_gpa` (float), `capacity` (int), `current_students` (int), `is_available` (bool).
- **Методы:**
  - `is_suitable_for(student_course, gpa) -> bool` — проверка соответствия соискателя требованиям;
  - `has_free_capacity() -> bool` — проверка наличия свободных мест по квоте;
  - `reserve_slot() -> bool` — инкапсулированное занятие места на тему с изменением статуса при исчерпании квоты;
  - `release_slot() -> None` — освобождение места при отмене заявки;
  - `@staticmethod validate_capacity(capacity) -> bool` — валидация корректности значения квоты;
  - `@classmethod from_dict(data) -> Topic` — фабричный метод создания объекта из JSON;
  - `to_dict() -> dict` — сериализация объекта в словарь;
  - `__str__() -> str` — полиморфное строковое представление.

#### 2. Класс `Student` (`models/students.py`)
Описывает соискателя темы (пользователя системы):
- **Атрибуты:** `id` (int), `name` (str), `course` (int), `gpa` (float), `is_budget` (bool), `email` (str).
- **Методы:**
  - `calculate_priority() -> int` — вычисление рейтинга заявки на основе GPA и формы обучения;
  - `@classmethod from_dict(data) -> Student` — создание объекта из словаря JSON;
  - `to_dict() -> dict` — сериализация объекта в словарь;
  - `__str__() -> str` — строковое представление.

#### 3. Класс `Application` (`models/applications.py`)
Осуществляет композицию сущностей предметной области:
- **Атрибуты:** `id` (int), `topic` (`Topic`), `student` (`Student`), `application_date` (str), `priority` (int), `is_cancelled` (bool).
- **Методы и свойства:**
  - `cancel() -> None` — отмена заявки с вызовом метода `self.topic.release_slot()`;
  - `@property status -> str` — динамическое свойство («ОДОБРЕНА» / «ОТМЕНЕНА»);
  - `to_dict() -> dict` — сохранение внешних ключей `topic_id` и `student_id` для JSON;
  - `__str__() -> str` — форматированное представление карточки заявки.

### 3.2. Диаграмма взаимодействия объектов
