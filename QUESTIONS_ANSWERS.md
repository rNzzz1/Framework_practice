# Ответы на контрольные вопросы к Практической работе № 1

## По материалам Яндекс Практикума

### 1. Какие основные типы данных используются в Python?
Базовые скалярные типы:
- Целые числа (`int`)
- Вещественные числа / числа с плавающей точкой (`float`)
- Строки (`str`)
- Логический / булев тип (`bool`)
- Специальный тип отсутствия значения (`NoneType` / `None`)
Также в языке есть встроенные составные типы (коллекции): списки (`list`), кортежи (`tuple`), словари (`dict`), множества (`set`).

### 2. Чем отличаются int, float, str и bool?
- `int` — целые знаковые числа произвольной точности (например, `42`, `-5`).
- `float` — числа с плавающей точкой двойной точности по стандарту IEEE 754 (например, `3.14`, `-0.5`).
- `str` — неизменяемая последовательность символов в кодировке Unicode (например, `"Привет"`).
- `bool` — логический тип, принимающий только два значения: `True` (истина) или `False` (ложь).

### 3. Для чего используется преобразование типов?
Преобразование типов (приведение типов) используется для явного приведения значения одной природы к другой (например, строки, введенной пользователем, к числу `int("3")` для вычислений, или числа к строке `str(101)` для конкатенации/вывода). В Python динамическая, но строгая типизация, поэтому неявное смешивание несовместимых типов (например, строки и числа) вызывает ошибку `TypeError`.

### 4. Какие операции можно выполнять со строками?
- Конкатенация (сложение строк: `"a" + "b"`);
- Дублирование / умножение (`"abc" * 3`);
- Индексация и срезы (`s[0]`, `s[1:4]`, `s[::-1]`);
- Форматирование (f-строки `f"{x}"`, метод `format()`, `%`);
- Методы строк: поиск (`find`, `count`), изменение регистра (`lower`, `upper`, `title`), разделение и склеивание (`split`, `join`), удаление пробельных символов (`strip`).

### 5. Какие операторы сравнения используются в Python?
- `==` (равно)
- `!=` (не равно)
- `>` (больше), `<` (меньше)
- `>=` (больше или равно), `<=` (меньше или равно)
- `is`, `is not` (проверка идентичности объектов в памяти)

### 6. Для чего используется конструкция if?
Конструкция `if` (условный оператор) используется для ветвления логики выполнения программы: блок кода под `if` исполняется только в том случае, если заданное условие вычисляется в `True`.

### 7. В чем различие между if, elif и else?
- `if` — первое обязательное условие ветвления.
- `elif` (else if) — дополнительные взаимоисключающие проверки, которые проверяются последовательно, только если предшествующие условия оказались ложными.
- `else` — блок "по умолчанию", выполняемый, если ни одно из условий `if` и `elif` не вернуло `True`.

### 8. Как записываются составные условия?
Составные условия объединяются логическими операторами `and` (логическое И), `or` (логическое ИЛИ), `not` (отрицание), а также группируются круглыми скобками `()` для задания приоритета. Python также поддерживает сцепленные сравнения: `min_val <= x <= max_val`.

### 9. Для чего используются логические операторы and, or и not?
- `and` — возвращает истину только в том случае, если оба операнда истинны (при коротком замыкании возвращает первый ложный или последний истинный).
- `or` — возвращает истину, если хотя бы один из операндов истинен (возвращает первый истинный или последний ложный).
- `not` — инвертирует логическое значение (меняет `True` на `False` и наоборот).

### 10. Что такое модуль Python?
Модуль в Python — это отдельный файл с расширением `.py`, содержащий определения функций, классов, переменных и исполняемый код, предназначенный для повторного использования и логической структуризации проекта.

### 11. Для чего используется import?
Оператор `import` используется для подключения и загрузки внешних модулей, пакетов или отдельных объектов из стандартной библиотеки Python, сторонних библиотек или собственных файлов проекта.

### 12. Чем импорт модуля отличается от импорта отдельного объекта из модуля?
- При `import module_name` загружается весь модуль, а доступ к его объектам осуществляется через точечную нотацию: `module_name.function_name()`.
- При `from module_name import function_name` в локальное пространство имен импортируется конкретная функция или класс, и к ним можно обращаться напрямую по имени `function_name()`.

## По рабочему окружению

### 13. Для чего используется виртуальное окружение Python?
Виртуальное окружение (например, `.venv`) изолирует зависимости и версии интерпретатора конкретного проекта от глобальной системы и других проектов. Это предотвращает конфликты версий библиотек и пакетов.

### 14. Что такое IDE?
IDE (Integrated Development Environment) — интегрированная среда разработки (например, VS Code, PyCharm). Предоставляет комплекс инструментов: текстовый редактор с подсветкой синтаксиса и автодополнением, отладчик, терминал, интеграцию с Git и линтерами.

### 15. Для чего используется Git?
Git — распределенная система контроля версий, предназначенная для отслеживания изменений в исходном коде, совместной работы, ветвления и возможности возврата к любой предыдущей версии проекта.

### 16. Что такое репозиторий?
Репозиторий — это хранилище проекта (каталог с кодом) вместе со служебной папкой `.git`, где содержится вся история изменений, коммитов, веток и конфигурация.

### 17. Что такое commit?
Коммит (commit) — это зафиксированное состояние (снимок/снапшот) файлов проекта в определенный момент времени с уникальным хэшем (SHA-1), автором, датой и сопроводительным сообщением.

### 18. Для чего нужен .gitignore?
Файл `.gitignore` указывает системе Git, какие файлы и директории не следует отслеживать и включать в коммиты (файлы виртуального окружения `.venv/`, кэш байт-кода `__pycache__/`, временные файлы операционной системы, секреты, ключи и базы данных).

### 19. Для чего нужен README.md?
Файл `README.md` (написанный в формате Markdown) является визитной карточкой репозитория. В нем фиксируются назначение проекта, инструкции по установке и запуску, описание архитектуры, сущностей и контактная информация.

### 20. Что такое отладка?
Отладка (debugging) — процесс обнаружения, анализа, локализации и устранения логических и программных ошибок (багов) в коде приложения.

### 21. Что такое breakpoint?
Breakpoint (точка останова) — отметка в строке исходного кода, при достижении которой среда выполнения или отладчик приостанавливает выполнение программы, позволяя разработчику исследовать состояние памяти и переменных.

### 22. Для чего используется пошаговое выполнение программы?
Пошаговое выполнение (Step Over, Step Into, Step Out) позволяет выполнять код строка за строкой, анализировать порядок ветвления, вызовы функций и изменения значений переменных в реальном времени.

## По индивидуальному проекту

### 23. Какую задачу решает выбранное приложение?
Сервис решает задачу автоматизации и упорядочивания процесса выбора и закрепления тем курсовых работ студентами: устраняет рутину бумажных заявлений, предотвращает выбор одной и той же темы несколькими студентами и автоматически проверяет академический допуск.

### 24. Кто является предполагаемым пользователем?
- Студенты (выбирают темы, подают заявки);
- Научные руководители / преподаватели (публикуют темы, рецензируют и утверждают заявки);
- Учебный отдел / деканат / заведующий кафедрой (контроль распределения и сроков).

### 25. Какие основные сущности выделены в предметной области?
1. **Студент** (`Student`): ФИО, номер зачетной книжки, курс, средний балл (GPA), форма обучения;
2. **Дисциплина** (`Discipline`): наименование, семестр, минимальный курс;
3. **Тема курсовой работы** (`Topic`): название, дисциплина, научный руководитель, статус доступности;
4. **Заявка** (`Application`): номер, студент, тема, дата подачи, приоритет, статус одобрения.

### 26. Какие функции планируется реализовать?
- Проверка доступности темы для выбора;
- Валидация допуска студента по академическим требованиям (курс, GPA);
- Расчет приоритета рассмотрения заявки;
- Формирование сводной карточки заявки;
- В перспективе: регистрация/авторизация, веб-интерфейс на Django, REST API, хранение в реляционной БД.

### 27. Какой сценарий реализован на текущем этапе?
В скрипте `main.py` реализован начальный законченный сценарий: инициализация данных студента, дисциплины и темы; валидация допуска студента по курсу и среднему баллу; проверка доступности темы; расчет приоритета заявки; вынесение решения об утверждении/отклонении; форматирование и вывод карточки заявки с датой подачи.

### 28. Какие конструкции Python использованы в программе?
- Простые типы: `int`, `float`, `str`, `bool`;
- Модули: импорт `date` из стандартного модуля `datetime`;
- Операции: сравнение (`>=`, `==`), логические операторы (`and`), тернарный оператор (`... if ... else ...`), арифметические операции;
- Приведение типов: `int()`, `float()`, строковое форматирование дат `strftime()`;
- Условные конструкции: `if-else`;
- Пользовательские функции с аннотациями типов аргументов и возвращаемых значений;
- Точка входа через идиому `if __name__ == "__main__":`.

### 29. Какие части проекта будут добавлены после изучения ООП и Django?
- **ООП (ПР3):** сущности `Student`, `Discipline`, `Topic`, `Application` будут оформлены полноценными классами с методами, инкапсуляцией и валидацией;
- **Django и Базы данных (ПР5–ПР10):** миграции, ORM-модели для PostgreSQL/SQLite со связями Foreign Key, маршрутизация URL, view-контроллеры, шаблоны страниц или REST API, формы валидации, система аутентификации пользователей и прав доступа.

### 30. Почему выбранная предметная область подходит для дальнейшей реализации в виде веб-приложения?
Данная область идеально ложится на архитектуру клиент-серверного веб-приложения:
- Имеется несколько четко выраженных ролей пользователей (студент, преподаватель, администратор) с разными правами доступа;
- Требуется централизованная база данных с реляционными связями (один преподаватель ведет много тем, одна заявка связывает студента и тему);
- Требуется конкурентный доступ через веб-браузер и интерактивное отображение актуальных статусов (свободна/занята);
- Логика легко масштабируется на REST API для интеграции с мобильными приложениями или личным кабинетом вуза.
