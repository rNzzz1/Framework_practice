# Сервис выбора тем курсовых работ

Консольное приложение для автоматизации учета тем курсовых проектов и управления подачей и согласованием заявок студентов.

## Назначение
Сервис предназначен для автоматизации и регламентации процесса распределения тем курсовых проектов и работ между студентами и преподавателями кафедры. Система решает проблемы непрозрачности распределения тем, конфликтов одновременного выбора одной темы несколькими студентами, исключает рутинную обработку бумажных заявлений и обеспечивает автоматическую проверку академических требований к студенту при подаче заявки.

## Целевая аудитория
- **Студенты**: просмотр списка актуальных дисциплин и тем курсовых работ, проверка собственного допуска, подача электронных заявок на закрепление темы, отслеживание статуса рассмотрения заявки.
- **Преподаватели (научные руководители)**: формирование и редактирование перечня тем по закрепленным дисциплинам, рецензирование и утверждение заявок студентов.
- **Учебный отдел и сотрудники кафедры**: административный контроль распределения тем, мониторинг соблюдения дедлайнов подачи заявок, выгрузка итоговых приказов и ведомостей.

## Предметная область
Предметная область охватывает процесс организации курсового проектирования в высшем учебном заведении. Основной рабочий процесс включает формирование каталога тем по академическим дисциплинам, проверку соответствия студента установленным критериям (курс обучения, академическая успеваемость GPA), подачу заявки на закрепление темы, учет статуса доступности темы и вынесение решения об утверждении заявки.

## Основные сущности
- **Студент (Student)**: ФИО, номер зачетной книжки, текущий курс обучения, средний академический балл (GPA), форма обучения (бюджетная/договорная).
- **Дисциплина (Discipline)**: наименование дисциплины, семестр преподавания, минимальный курс обучения для записи.
- **Тема курсовой работы (Topic)**: наименование темы, закрепленная дисциплина, преподаватель (научный руководитель), минимальный курс, минимальный GPA, квота мест, текущее число студентов, статус доступности для выбора (свободна / занята).
- **Заявка (Application)**: номер заявки, дата подачи, выбранная тема, заявитель (студент), курс, средний балл GPA, форма обучения, вычисленный приоритет рассмотрения, статус решения (ОДОБРЕНА / ОТМЕНЕНА).

## Возможности приложения (ПР2)
- Просмотр полного перечня тем курсовых работ с форматированным табличным выводом;
- Поиск тем по ключевым словам в названии, дисциплине или ФИО руководителя;
- Фильтрация тем по выбранной академической дисциплине с использованием генераторов;
- Проверка доступности темы и свободных мест по квоте;
- Подача новой заявки с комплексной валидацией допуска студента (курс >= min_course, GPA >= min_gpa);
- Автоматический расчет численного приоритета заявки;
- Защита от повторной подачи заявки тем же студентом на ту же тему;
- Отмена ранее поданной заявки с автоматическим освобождением квоты темы;
- Формирование структурированной текстовой карточки заявки;
- Сводный аналитический расчет статистики (общее число заявок, одобренные, отмененные, средний балл GPA студентов);
- Сохранение и персистентная загрузка данных в формате JSON с защитой от повреждений;
- Безопасный ввод данных с консоли с обработкой исключений (`ValueError`).

## Структура проекта
```text
Frameworks-practice/
│
├── README.md               # Документация проекта
├── requirements.txt        # Список зависимостей разработки (pytest, flake8)
├── main.py                 # Точка запуска приложения и текстовое меню
├── topics.py               # Функции работы с темами курсовых работ
├── applications.py         # Функции создания, отмены и статистики заявок
├── storage.py              # Функции сохранения и загрузки данных из JSON
├── utils.py                # Вспомогательные функции безопасного ввода с валидацией
│
├── data/                   # Каталог персистентных данных JSON
│   ├── topics.json         # Хранилище тем курсовых работ
│   └── applications.json   # Хранилище поданных заявок
│
└── tests/                  # Каталог автоматизированных тестов
    ├── test_topics.py      # Модульные тесты функционала тем
    └── test_applications.py# Модульные тесты функционала заявок
```

## Требования
- Python 3.10+
- pytest >= 8.0
- flake8 >= 7.0

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
Запуск интерактивного меню:
```bash
python3 main.py
```

Запуск сквозного демонстрационного сценария (без ожидания ввода):
```bash
python3 main.py --demo
```

## Запуск тестов
Запуск через pytest:
```bash
pytest
```

## Проверка качества кода
Проверка соответствия PEP 8 линтером flake8:
```bash
flake8 . --count --max-line-length=120 --statistics
```
