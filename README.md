# Сервис выбора тем курсовых работ

## Назначение
Сервис предназначен для автоматизации и регламентации процесса распределения тем курсовых проектов и работ между студентами и преподавателями кафедры. Система решает проблемы непрозрачности распределения тем, конфликтов одновременного выбора одной темы несколькими студентами, исключает рутинную обработку бумажных заявлений и обеспечивает проверку академических требований к студенту при подаче заявки.

## Целевая аудитория
- **Студенты**: просмотр списка актуальных дисциплин и тем курсовых работ, проверка собственного допуска, подача электронных заявок на закрепление темы, отслеживание статуса рассмотрения заявки.
- **Преподаватели (научные руководители)**: формирование и редактирование перечня тем по закрепленным дисциплинам, рецензирование и утверждение заявок студентов.
- **Учебный отдел и сотрудники кафедры**: административный контроль распределения тем, мониторинг соблюдения дедлайнов подачи заявок, выгрузка итоговых приказов и ведомостей.

## Предметная область
Предметная область охватывает процесс организации курсового проектирования в высшем учебном заведении. Основной рабочий процесс включает формирование каталога тем по академическим дисциплинам, проверку соответствия студента установленным критериям (курс обучения, академическая успеваемость), подачу заявки на закрепление темы, учет статуса доступности темы и вынесение решения об утверждении заявки.

## Основные сущности
- **Студент (Student)**: ФИО, номер зачетной книжки, текущий курс обучения, средний академический балл (GPA), форма обучения (бюджетная/договорная).
- **Дисциплина (Discipline)**: наименование дисциплины, семестр преподавания, минимальный курс обучения для записи.
- **Тема курсовой работы (Topic)**: наименование темы, закрепленная дисциплина, преподаватель (научный руководитель), статус доступности для выбора (свободна / занята).
- **Заявка (Application)**: номер заявки, дата подачи, выбранная тема, заявитель (студент), вычисленный приоритет рассмотрения, статус решения (на рассмотрении / одобрена / отклонена).

## Основные функции
- **Проверка доступности темы (`check_topic_availability`)**: определение текущего статуса темы и возможности ее выбора студентом.
- **Валидация соответствия студента требованиям (`validate_student_eligibility`)**: проверка допуска студента к выбору темы по курсу обучения и минимально допустимому среднему баллу (GPA).
- **Расчет приоритета заявки (`calculate_application_priority`)**: расчет численного приоритета рассмотрения заявки на основе успеваемости (GPA) и формы обучения.
- **Формирование сводки по заявке (`format_application_summary`)**: генерация итоговой карточки заявки с детализацией решения, даты подачи и основных сведений.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
