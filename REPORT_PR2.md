## 3. Индивидуальный проект

- **Название проекта:** Сервис выбора тем курсовых работ
- **Перечень функций, реализованных на ПР2:**
  1. `topics.add_topic()` — добавление новой темы с автоматической генерацией ID и начальной квотой;
  2. `topics.find_topics()` — поиск тем по ключевой подстроке в названии, дисциплине или ФИО руководителя;
  3. `topics.check_topic_capacity()` — проверка наличия свободных мест по квоте темы;
  4. `topics.is_topic_available()` — проверка статуса темы и доступности мест;
  5. `topics.filter_topics_by_discipline()` — фильтрация перечня тем по дисциплине с генератором;
  6. `topics.sort_topics_by_title()` / `sort_topics_by_gpa()` — сортировка с lambda-функцией;
  7. `topics.get_topic_status()` — текстовый статус доступности темы (преемственность ПР1);
  8. `applications.validate_student_eligibility()` — валидация соответствия критериям (курс, GPA) (ПР1);
  9. `applications.calculate_application_priority()` — расчет приоритета заявки (ПР1);
  10. `applications.is_student_already_applied()` — проверка дублирования активных заявок;
  11. `applications.create_application()` — создание заявки, валидация, резервирование места темы;
  12. `applications.cancel_application()` — отмена заявки и восстановление квоты темы;
  13. `applications.get_applications_statistics()` — расчет аналитической сводки по заявкам;
  14. `applications.format_application_summary()` — форматирование карточки заявки (ПР1);
  15. `storage.load_topics()` / `save_topics()` — сериализация/десериализация тем в JSON;
  16. `storage.load_applications()` / `save_applications()` — сохранение/чтение заявок в JSON;
  17. `utils.input_int()`, `input_float()`, `input_date()`, `input_str()` — безопасный ввод с обработкой `ValueError`;
  18. `main.show_topics()`, `main.show_applications()`, `main.main()` — форматированный вывод и интерактивное меню.
- **Структура модулей проекта:**
  - `main.py` — координация программы, текстовое меню, цикл обработки команд;
  - `topics.py` — бизнес-логика работы с темами курсовых работ;
  - `applications.py` — бизнес-логика создания, отмены и аналитики заявок;
  - `storage.py` — модуль сохранения и загрузки данных через контекстные менеджеры `with open()`;
  - `utils.py` — вспомогательные функции безопасного ввода с валидацией;
  - `data/` — каталог персистентных JSON-файлов (`topics.json`, `applications.json`);
  - `tests/` — модульные тесты pytest (`test_topics.py`, `test_applications.py`).
- **Формат хранения данных:** JSON-файлы со списками словарей (`data/topics.json`, `data/applications.json`), с кодировкой UTF-8 и отступами `indent=2`.
